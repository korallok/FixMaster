# Выполнение практической работы FixMaster

Основание: задание «3 уп.docx», онлайн-платформа заказа ремонта компьютеров и оргтехники. Результат — отдельный работающий проект на Node.js и SQLite.

| Требование | Реализация | Проверка |
| --- | --- | --- |
| Дизайн всех страниц 390×844 | Восемь отдельных HTML-файлов, CSS media queries, мобильное меню | Скриншоты восьми страниц, проверка горизонтального переполнения |
| Четыре одинаковых изображения | Оригинальные SVG 640×560 в public/assets | Проверка загрузки изображений в браузере |
| Автопрокрутка через 3 секунды | setInterval 3000, стрелки вперёд/назад, индикаторы, пауза | Проверка смены активного слайда через 3100 мс и ручного переключения |
| Оптимизация графики | Компактные локальные SVG, общие размеры и палитра, без внешних запросов | Проверка пропорций и загрузки |
| Регистрация и сохранение в базе | POST /api/register, SQLite users, уникальный email | Проверки корректных/ошибочных полей и дубликата email |
| Ошибки на форме | Сообщение формы и подписи к отдельным полям, aria-invalid | Проверка пустой заявки в мобильном браузере |
| Авторизация | POST /api/login, cookie сессии, роли client/admin | Проверки неверного пароля и доступа |
| Отзыв только после выполнения | Проверка владельца, статуса done и отсутствия прежнего отзыва | До выполнения 403, для чужой заявки 404, повторный отзыв 409 |
| Четыре типа устройств | Ноутбук, Стационарный ПК, Принтер/МФУ, Планшет | Выпадающий список и серверная проверка |
| Неисправность и календарь визита | textarea, datetime-local, форматированный предпросмотр ДД.ММ.ГГГГ ЧЧ:ММ | Проверка создания заявки и будущего времени |
| Фильтры администратора | Совместный выбор устройства и одного из четырёх статусов | API и браузерная проверка |
| Уведомление о назначении | Toast после успешного сохранения мастера на сервере | Проверка видимости уведомления |
| Пагинация | По пять заявок на странице, номер страницы, кнопки | API и браузерная проверка второй страницы |
| Контроль версий | Отдельный Git-репозиторий, начальный и завершающий коммиты | История Git и удалённая ветка main |

Изображения для обработки не приложены к исходному документу. Вместо них созданы четыре согласованные векторные иллюстрации устройств. Используются стандартные модули Node.js для HTTP, криптографии и SQLite; сервер работает без установки сторонних зависимостей. Браузерные проверки используют Playwright и Microsoft Edge.

Для демонстрации предусмотрены отдельные клиентский и административный аккаунты. Инструкция запуска и реквизиты учебных аккаунтов находятся в README.md.
