Информация об учебном сервисе

Обработка данных

FixMaster — демонстрационный проект для учебной практики.

Какие данные сохраняются

При регистрации сохраняются имя, email, телефон и хеш пароля. В заявке хранятся тип устройства, описание неисправности и время визита. Отзыв связывается с выполненной заявкой.


Для чего нужны данные

Они используются для входа в личный кабинет и демонстрации обработки ремонта. Администратор видит данные клиента для назначения мастера. Учебный сервис не принимает оплату и не отправляет заявки в реальный сервисный центр.


Хранение и доступ

Данные хранятся в локальной базе SQLite на компьютере, где запущен сервер. Для входа используется cookie сессии сроком на одни сутки. В учебной версии используйте вымышленные сведения и отдельный пароль.
